# ConstructPro ERP - Frontend

## Project Description

This repository contains the client-side code (web application) for the **ConstructPro ERP** system, built for Ishara Homes Pvt. Ltd. It provides a user-friendly interface for lead management, quotation generation, project tracking, financial monitoring, and analytics dashboards.

**Broader Project:** [ConstructPro ERP Organization](https://github.com/ConstructPro-ERP)

## Technology Stack

- **Framework**: Next.js (v16.2.6)
- **UI Library**: React (v19.2.4)
- **Styling & Linting**: Airbnb Style Guide, ESLint, Prettier

## Prerequisites

- Node.js 22+
- Environment Variables (see `.env.example`)

## Installation & Run Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ConstructPro-ERP/frontend.git
   cd frontend
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Set up environment variables:**
   Copy `.env.example` to `.env` and configure API endpoint URLs.
   ```bash
   cp .env.example .env
   ```
4. **Run the application (Development):**
   ```bash
   npm run dev
   ```
